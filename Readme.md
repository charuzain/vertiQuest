List of Anchor Pseudo Classes
:link: used to apply styles to non-visited links
:visited: used to apply styles to visited links
:hover: used to apply styles when the mouse cursor moves over the link
:active: used to apply styles to an active link. A link becomes active when the user clicks on it.
